# Project

This project is based on [Encore](https://encore.dev/). It provides the following services:

Business:
* **Hista** provides an API to manage a meal, symptom, headache and pollen diary.
* **Shopping List** provides an API to manage a shopping list.

Utility:
* **Authentication** manages logins.
*** Product Management** contains all products and manages product instances.
* **Users** manages users.

The corresponding UIs are https://github.com/bbrighter/shopping-list-ui and https://github.com/bbrighter/shopping-list-ui. 

## Setup
* Install [Golang](https://go.dev/doc/install).
* Install [Encore](https://encore.dev/docs/go/install).
* Run via `encore run`.
